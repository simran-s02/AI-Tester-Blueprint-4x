### Objective

The objective of this Test Plan is to define an industry-level testing approach for the VWO – Digital Experience Optimization

Platform.

Application Under Test (AUT): VWO

URL: https://app.vwo.com/#/login

The purpose of testing is to verify the functional and non-functional requirements documented in the VWO Product

Requirements Document (PRD).

The VWO PRD describes the platform as a digital experience optimization platform supporting experimentation, behavioral

insights, personalization, program and workflow management, and integrations with external platforms.

This Test Plan is generated using the RICEPOT framework specified for the assignment. RICEPOT is used as the framework

for generating the Test Plan; the final Test Plan follows the structure of the provided Software Test Plan Template.

### Scope

The scope of testing is limited to the functionality and quality requirements explicitly documented in the VWO PRD.
