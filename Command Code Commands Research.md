# Task 2: Command Code Commands Research

Command Code provides several built-in slash commands to improve productivity during AI-assisted development.

## 1. `/goal`
Sets a persistent objective for the current session, allowing the AI to stay focused on a specific task without needing repeated instructions.

## 2. `/compact`
Compresses the conversation history while preserving the essential context, making long coding sessions more efficient and reducing context usage.

## 3. `/mcp`
Manages Model Context Protocol (MCP) servers, enabling Command Code to connect with external tools and services such as GitHub, databases, Notion, and APIs.

## Summary
The `/goal`, `/compact`, and `/mcp` commands help maintain focus, optimize context, and extend Command Code's capabilities through external integrations, resulting in a more efficient development workflow.
